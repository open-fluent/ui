# Fluent UI Framework

[Created with ❤ in Poland by Leszek Pomianowski](https://lepo.co/) and [open-source community](https://github.com/open-fluent/ui/graphs/contributors).  
A collection of small, independent .NET libraries that wrap common infrastructure with a chainable API.
